# 零花钱管家 — 功能需求文档

> 版本：v2.0.0 | 更新日期：2026-10-11

## 1. 产品概述

零花钱管家是一款面向家庭的儿童零花钱管理 Web 应用，采用移动端优先的 iOS 风格设计。无需登录注册，家庭共享一个账本，支持多个孩子各自独立管理余额、消费记录和理财组合。

**技术栈：** React 19 + TailwindCSS v4 + Vite 7（前端）、Express 4.21 + SQLite（Node 22 内置 `node:sqlite`）（后端）

**核心约束：** 全链路金额单位为「分」（整数），避免浮点精度问题。

## 2. 数据模型

### 2.1 孩子（children）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PK | 自增前缀 ID，如 `c1`、`c2` |
| name | TEXT | 昵称，最长 12 字符 |
| avatar | TEXT | Emoji 头像，默认 🧒 |
| color | TEXT | 主题色（十六进制），默认 #007AFF |
| created_at | INTEGER | 创建时间戳（毫秒） |

### 2.2 交易记录（transactions）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PK | 自增前缀 ID，如 `t1` |
| child_id | TEXT FK | 所属孩子（级联删除） |
| type | TEXT | 类型：`deposit` / `expense` / `invest` / `redeem` |
| amount | INTEGER | 金额（分）；入金/赎回为正，消费/买入理财为负 |
| item | TEXT | 项目名称，最长 20 字符 |
| note | TEXT | 备注，最长 60 字符 |
| category | TEXT | 消费分类键（仅 expense 有值）：snack / toy / study / book / fun / other |
| date | TEXT | 日期 YYYY-MM-DD |
| created_at | INTEGER | 创建时间戳（毫秒） |

索引：`(child_id, date)` 联合索引。

### 2.3 理财持仓（investments）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PK | 自增前缀 ID，如 `i1` |
| child_id | TEXT FK | 所属孩子（级联删除） |
| product_id | TEXT | 产品 ID |
| product_name | TEXT | 购买时的产品名称快照 |
| rate | REAL | 购买时的年化利率 |
| term_days | INTEGER | 期限天数（0 = 活期） |
| amount | INTEGER | 本金（分） |
| start_date | TEXT | 买入日期 YYYY-MM-DD |
| redeemed_at | TEXT | 赎回日期；NULL 表示持仓中 |

索引：`(child_id)` 索引。

### 2.4 计数器（counters）

用于生成自增 ID。三行记录：`child`、`tx`、`invest`，各存储当前序列号。

## 4. 业务规则

### 4.1 收益计算

- **公式：** 每日收益 = round(本金 × 年化利率 ÷ 365)（四舍五入到分）
- **T+1 起息：** 买入当天不计息，次日开始产生收益
- **计息截止日：** min(赎回日, 到期日（定期产品）, 今天)
- **逐日四舍五入：** 每天的利息独立取整，保证日收益累加 = 总累计收益
- **定期产品：** 到期后不再计息（演示环境不罚息）
- **活期产品：** 无到期日，持续计息到今天

### 4.2 余额计算

- **现金（cash）：** 所有交易金额之和（入金/赎回为正，消费/买入为负）
- **理财中（invested）：** 所有未赎回持仓的本金之和
- **累计收益（accrued）：** 所有未赎回持仓的累计利息之和
- **总资产（total）：** cash + invested + accrued

### 4.3 余额约束

- 现金余额不可为负数
- 消费金额不可超过可用现金（否则提示"零花钱不够啦，先入金或赎回理财"）
- 买入理财金额不可超过可用现金
- 删除交易后，若导致现金为负则拒绝删除
- 单笔交易上限：10,000,000 分（10 万元）
- 最低理财买入：100 分（1 元）

### 4.4 日期规则

- 日期格式为本地 YYYY-MM-DD 字符串（无时区问题）
- 交易日期不可为未来日期
- 默认日期为今天

## 5. API 接口

所有接口的金额字段单位均为「分」。

### 5.1 健康检查

```
GET /api/health
→ { ok: true, time: <ms> }
```

### 5.2 家庭概览

```
GET /api/overview
→ {
    children: [{ id, name, avatar, color, createdAt,
      balances: { cash, invested, accrued, total } }],
    family: { cash, invested, accrued, total, monthIncome }
  }
```

`monthIncome` 为所有孩子近 30 天收益系列总和。

### 5.3 产品列表

```
GET /api/products
→ { products: [...] }
```

### 5.4 添加孩子

```
POST /api/children
Body: { name, avatar?, color?, initialBalance? }
→ 201 { child: { id, name, avatar, color, createdAt, balances } }
```

- 名字最长 12 字符，头像最长 8 字符，颜色最长 16 字符
- `initialBalance` 上限 10,000,000 分
- 若 `initialBalance > 0`，自动创建一笔"初始零花钱"入金记录

### 5.5 删除孩子

```
DELETE /api/children/:id
→ { ok: true }
```

级联删除该孩子的所有交易和理财记录。

### 5.6 孩子详情

```
GET /api/children/:id
→ {
    child: { id, name, avatar, color, createdAt },
    balances: { cash, invested, accrued, total },
    transactions: [...],
    investments: [{ id, productId, productName, rate, termDays, amount,
      startDate, redeemedAt, accrued, ratePct, matureDate, daysLeft, matured }]
  }
```

投资列表仅返回未赎回记录，按买入日期倒序。每条包含计算字段：`accrued`（累计收益）、`ratePct`（利率百分比）、`matureDate`（到期日）、`daysLeft`（剩余天数）、`matured`（是否已到期）。

### 5.7 记交易

```
POST /api/children/:id/transactions
Body: { type: 'deposit'|'expense', amount, date?, item?, note?, category? }
→ 201 { transaction: {...}, balances: {...} }
```

**入金（deposit）：** `item` 默认"入金"，金额为正。

**消费（expense）：** `item` 必填（最长 20 字符），`category` 默认 `other`，金额存储为负数。校验现金余额是否充足。

**通用校验：** 金额必须为正整数（分），不超过 10,000,000；日期不可为未来。

### 5.8 删除交易

```
DELETE /api/transactions/:id
→ { ok: true, balances: {...} }
```

删除后反向冲正交易效果。若删除后现金余额为负则拒绝。

### 5.9 收益系列

```
GET /api/children/:id/income?days=7|30|90
→ { days, from, to, series: [{ date, income }], total }
```

返回指定天数范围内每日收益数组，`total` 为合计。

### 5.10 买入理财

```
POST /api/children/:id/investments
Body: { productId, amount }
→ 201 { investment: {...}, balances: {...} }
```

最低 100 分，不超过可用现金。同时创建一条 `invest` 类型交易记录（金额为负）。

### 5.11 赎回理财

```
POST /api/investments/:id/redeem
→ { investment: {...}, balances: {...}, gain: number }
```

不可重复赎回。计算截至赎回日的累计收益，设置 `redeemed_at` 为今天，创建一条 `redeem` 交易（金额 = 本金 + 收益），备注含明细"本金 ¥X.XX，收益 ¥Y.YY"。

### 5.12 重置演示数据

```
POST /api/demo/reset
→ { ok: true, children: [...], family: {...} }
```

清空所有数据并重新生成演示数据。

## 7. 前端页面与交互

### 7.1 导航结构

底部 4 个 Tab：首页 | 记账 | 理财 | 管理

### 7.2 首页（HomeView）

- **家庭总资产：** 数字滚动动画展示（ease-out 缓动 560ms）
- **资产概览行：** 现金 | 理财中 | 近 30 天收益
- **快捷操作：** 记消费（−）| 入金（＋），默认选中第一个孩子
- **孩子列表：** 卡片式展示头像、姓名、理财中金额、总资产、可用零花钱
- **空状态：** 无孩子时提示创建
- **孩子卡片点击：** 弹出快捷操作弹窗（记消费 / 入金 / 去理财 / 查看明细），点击后自动关闭弹窗并跳转对应页面和表单

### 7.3 记账页（LedgerView）

- **孩子选择器：** 顶部横向滚动标签
- **余额统计：** 可用零花钱 | 理财中 | 总资产
- **快捷按钮：** 记消费 | 入金
- **交易列表：** 按日期分组（今天 / 昨天 / M月D日 周X），每条展示分类图标、项目名、备注、金额
- **点击删除：** 任意交易记录可点击删除（弹出 iOS 风格确认对话框）
- **空状态：** 提示先入金

### 7.4 理财页（InvestView）

- **孩子选择器：** 顶部横向滚动标签
- **收益面板：**
  - 分段控件切换时间范围：近 1 周 / 近 1 月 / 近 3 月
  - 区间总收益（绿色）
  - 每日收益柱状图（当天蓝色实色，历史日期浅蓝）
  - 统计行：理财中本金 | 可用现金 | 累计收益
- **持仓列表：** 展示产品名、标签（活期/定期/理财）、年化利率、期限、本金、已赚收益
  - 已到期产品显示"已到期"标记
  - 7 天内到期的显示"N 天后到期"提示
- **点击赎回：** 弹出确认框，显示本金 + 收益明细
- **买入按钮：** 右上角，打开买入理财表单
- **空状态：** 提示先买入

### 7.5 管理页（ManageView）

- **孩子管理：** 列表展示头像、姓名、总资产，右侧删除按钮
- **添加孩子：** 列表底部按钮
- **数据管理：** "重置演示数据"按钮（需确认）
- **关于：** 版本号、技术栈说明、产品利率信息（演示数据）、使用方式说明
- **底部说明：** 数据存储方式（SQLite，Docker 卷持久化）

## 11. 部署与配置

| 配置项 | 环境变量 | 默认值 | 说明 |
|--------|----------|--------|------|
| 端口 | PORT | 3000 | 服务监听端口 |
| 数据目录 | DATA_DIR | ./data/ | SQLite 数据库存放路径 |

**运行环境要求：** Node.js >= 22.12（使用内置 `node:sqlite`）

**生产模式：** Express 托管 `client/dist` 静态文件，SPA 回退到 `index.html`。

**开发模式：** Vite 开发服务器（端口 5173），`/api` 请求代理到后端端口 3000。

## 12. 冒烟测试覆盖

自动化冒烟测试（`scripts/smoke-test.mjs`）包含 30 项断言，覆盖：

1. 健康检查正常返回
2. 概览接口返回孩子列表且余额合法（cash >= 0，total = cash + invested + accrued）
3. 家庭总资产 > 0
4. 收益系列长度正确（7/30/90）
5. 收益系列总额 = 每日收益之和
6. 收益总额随范围单调递增（90 天 >= 30 天 >= 7 天）
7. 累计收益 = 实际持有天数 × 日利率（定期不会提前计入未来利息）
8. 创建孩子并设置初始余额
9. 入金正确增加现金
10. 消费正确减少现金
11. 余额不足消费被拒绝（400）
12. 非整数分金额被拒绝（400）
13. 未来日期被拒绝（400）
14. 买入理财正确减少现金
15. 当天买入收益为 0（T+1 起息）
16. 余额不足理财被拒绝（400）
17. 赎回返回本金 + 收益到现金
18. 当天赎回收益为 0
19. 重复赎回被拒绝（400）
20. 删除消费恢复现金
21. 删除导致负现金的交易被拒绝（400）
22. 资金已锁定在理财中时删除入金记录被拒绝（400）
23. 删除孩子成功并从概览移除
24. 重置演示数据恢复原始孩子数量和收益数据
